# Skill: PC Basics (safe house rules for this machine)

- Before editing any config (.env, openclaw.json, *.yaml): copy it to
  `<name>.bak-YYYYMMDD-HHmm` in the same folder first.
- Prefer reading logs over guessing: Ollama, the phone agent folder's
  logs, Windows Event Viewer for crashes.
- Long downloads/installs: tell the owner the size and an ETA first.
- Keep the PC awake while the phone line is live; check power settings
  rather than assuming (`powercfg /query`).
- Weekly tidy, only if the owner asks: list large files in Desktop and
  Downloads, propose deletions, delete nothing on your own.
- If a step needs a password, a verification code, a card, or a
  government ID: stop, tell the owner exactly which screen is waiting,
  and let him enter it on this PC himself.
